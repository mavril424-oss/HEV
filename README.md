# HEV
PROYECTO 1 HERRAMIENTAS DE VISUALIZACION

¡Bienvenido al repositorio de mi proyecto de visualización de datos de café (`ejerciciocafe`)!

## 📊 Descripción del Proyecto
Este repositorio contiene el desarrollo del modelo semántico y el reporte interactivo enfocado en el análisis de datos de cafetería utilizando Power BI.

* **Modelo Semántico:** `ejerciciocafe.SemanticModel`
* **Reporte / Dashboard:** `ejerciciocafe.Report`

## 🛠️ Tecnologías Utilizadas
* Power BI Desktop / Formato `.pbip`
* Modelado de datos
* Visualización de datos
